# Architecture

Technical structure of the [aidan.my](https://aidan.my) static site.

## Stack

- **HTML5** — one `index.html` per route, no templating engine.
- **CSS** — two stylesheets: [styles.css](assets/css/styles.css) (layout, components, design tokens) and [reveal.css](assets/css/reveal.css) (scroll-reveal animations).
- **JavaScript** — two scripts: [partials.js](assets/js/partials.js) (nav/footer injection) and [main.js](assets/js/main.js) (interactivity).
- **Fonts** — Plus Jakarta Sans and JetBrains Mono, loaded from Google Fonts.
- **Hosting** — GitHub Pages with the `aidan.my` apex domain (see [CNAME](CNAME)).

No bundler, no transpiler, no package manager. The site is shipped exactly as written.

## Page contract

Every page in the repo follows the same skeleton:

```html
<!DOCTYPE html>
<html lang="en" data-base="<relative-depth>" data-page="<slug>">
<head>
  <!-- per-page SEO: title, description, OG, Twitter, canonical, JSON-LD -->
  <link rel="stylesheet" href="<base>assets/css/styles.css" />
  <link rel="stylesheet" href="<base>assets/css/reveal.css" />
</head>
<body>
  <div id="nav-mount"></div>
  <!-- page content -->
  <div id="footer-mount"></div>
  <script src="<base>assets/js/partials.js"></script>
  <script src="<base>assets/js/main.js"></script>
</body>
</html>
```

**Critical attributes on `<html>`:**

- `data-base` — the relative path from this page back to the repo root. Used by `partials.js` to build asset URLs in the nav and footer.
  - Root (`/index.html`) → `data-base=""`
  - One level (`/group/index.html`) → `data-base="../"`
  - Two levels (`/people/culture/index.html`) → `data-base="../../"`
- `data-page` — the page slug, used by `partials.js` to mark the matching nav link as active.

## Shared partials

[partials.js](assets/js/partials.js) injects two HTML fragments into the mount points `#nav-mount` and `#footer-mount`. Both fragments reference assets via the resolved `${base}` prefix. To change the nav links, footer columns, social icons, or contact details, edit this file — not individual pages.

## Styling

[styles.css](assets/css/styles.css) defines:

- CSS custom properties for colors, gradients, fonts, spacing.
- Layout primitives: `.container`, `.bento`, `.section-head`, `.flex`.
- Components: `.btn`, `.bento-card`, `.icon-tile`, `.eyebrow`, `.chip`, `.cta-strip`, `.hero-*`, `.nav-*`, `.footer-*`.
- Page-specific blocks: `.page-header`, `.tile-image` (with `.contain` modifier for letterboxed logos).

[reveal.css](assets/css/reveal.css) defines the `.reveal` class plus delay modifiers `.d-1`, `.d-2`, `.d-3` used for staggered scroll-triggered animations. The intersection-observer logic lives in [main.js](assets/js/main.js).

## SEO

Each page declares its own canonical URL, Open Graph block, Twitter Card block, and JSON-LD. The home page also declares an `Organization` schema with `subOrganization` entries for the three group companies. Other pages declare `BreadcrumbList` schemas. Keep all URLs absolute and rooted at `https://aidan.my/`.

OG images live in [assets/images/og/](assets/images/og/) and are generated by [scripts/build-og-images.py](scripts/build-og-images.py).

[sitemap.xml](sitemap.xml) is hand-maintained — update it when adding or removing pages.
